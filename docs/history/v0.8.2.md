> [!IMPORTANT]
> **Upgrade notes.** Back up `./data` before updating the image with
> `docker compose up -d`; update `KANO_IMAGE` first if it is pinned. No
> database migration, environment change or API change. A locally built image
> builds from `docker/Dockerfile`: pass `-f docker/Dockerfile` to
> `docker build`.

v0.8.2 turns the board's **Next up** to **On air** within about a second of a
stream's start, shows a live stream's platforms as logos in one **On air**
label, and fills the streams-and-works column when nothing is coming up.
Schedule extraction reads its posts in batches and keeps an operator's
reprocess request made during a run. The README is reorganized around the
site's pages and links the Japan and mainland China servers.
